Design Rules
COLOUR USE Teal (#00685f) for primary actions, borders, active states, brand. Indigo (#4b41e1) for active chips, secondary actions, accent pills. Never mix teal and indigo in the same interactive element.
DATA COLOUR Green = positive/up, Red = negative/down, Yellow = pending/awaiting. Always pair a coloured value with its semantic label. Never use colour alone to convey meaning.
HOVER Stock rows: box-shadow: inset 3px 0 0 var(--primary) — no transform (prevents jitter). Buttons: opacity .88 or background change. Never move elements on hover.
DENSITY Stock rows: 54px min-height. Header: 56px. Cards: 12px padding default, 14px for panels. Font sizes: never below 9px. Labels always uppercase + letter-spacing at 9–11px.
SHADOWS Panels: 0 2px 16px rgba(75,65,225,.04). Buttons: 0 2px 8px rgba(0,104,95,.25) for primary. Avoid blur effects on frequently-updating elements (performance).
TYPOGRAPHY Always Hanken Grotesk. Numbers in tabular-nums (font-variant-numeric: tabular-nums). Brand: 800 weight. Headings: 700–800. Labels: 600. Body: 500. Captions: 400.
