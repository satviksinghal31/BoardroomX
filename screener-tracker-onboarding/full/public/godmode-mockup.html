Three monitoring dimensions — switch tabs to see each

📡 NSE Ticks — system heartbeat. Each tick = one cycle of the NSE bulk agent (2-min interval). Tells the admin "the agent IS alive" with aggregate counts. If you see no Tick rows for >5 min → something's broken.

⚡ NSE Events — actual signal. Per-company corporate events (dividends, earnings, AGMs, etc.). Has two sub-views:
Recent / Past: events that already happened (or are happening today) + ⏳ OUTCOME PENDING rows where the meeting date passed but NSE hasn't published the outcome yet.
Upcoming / Scheduled: future events sorted by soonest first.

📊 Screener — financial-numbers freshness. Each row = one Screener.in scrape. Shows whether numbers actually changed, were bootstrapped fresh, were unchanged (no-op), or failed (with reason).

Daily shift mechanic: A row sits in Upcoming while expected_at >= today. When that date arrives + NSE publishes the outcome → the row gets reported_at stamped → it disappears from Upcoming and shows in Recent. If the date passes but no outcome lands yet, it shows in Recent with the ⏳ OUTCOME PENDING chip until the bulk agent catches the outcome.

Action badges: ✚ ADDED new DB row · ✎ UPDATED existing field changed (diff shown) · ✓ NOOP checked, no change · ✗ FAILED error (with type badge)
