Summary
Style Pros Cons
A1 · Dot + Light popup Minimal, doesn't clutter. Green/red at a glance. Dot can be tiny on zoomed-out chart.
A2 · Dot + Dark tooltip Popup stands out against white chart. Slightly heavier feel.
B · Vertical line Unmissable, shows the exact result date clearly. Can clutter chart if 8+ lines visible.
My recommendation: Option A2 (dot + dark popup). Clean on chart, popup pops visually. Easy to implement reliably without LightweightCharts marker quirks — use CSS absolute-positioned dots instead.
